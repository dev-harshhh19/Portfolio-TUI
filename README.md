# Harshad Nikam — Terminal Portfolio

A terminal-based portfolio and virtual filesystem showcasing the software engineering work, systems architecture, and technical writings of Harshad Nikam.

Accessible via SSH at `cli.harshadnikam.me`.

---

## Overview

This portfolio is an interactive terminal application designed for recruiters, engineers, and collaborators to explore my background, production projects, technical articles, and engineering philosophy directly from their terminal without requiring web browsers or graphic interfaces.

### What is Inside

- Projects: Production applications, systems architecture case studies, and codebases.
- About: Background, technical focus areas, and engineering principles.
- Skills: Full-stack toolchain, backend architecture, cloud infrastructure, and databases.
- Writing: Technical articles and engineering writeups.
- Contact: Direct contact details and calendar scheduling.
